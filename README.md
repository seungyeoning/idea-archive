# 이 어플 어때? — 아이디어 아카이브

작은 발상을 앱과 게임의 기획·인터랙티브 시안으로 모은 정적 웹사이트입니다.

## 구성

- 앱 8개, 게임 1개
- 분류·검색·개별 아이디어 링크
- 6개의 조작 가능한 웹 시안과 2개의 소개영상
- 출시 제품, 기획, 예시 동작의 범위를 구분한 설명

`data.js`에서 아이디어 설명과 분류를 관리합니다. 증강 지우개 따먹기의 분류는 `game`입니다. `assets/`는 공개용 대표 자료, `demos/`는 각 시안의 정적 배포 사본입니다.

GitHub Pages의 프로젝트 하위 경로에서 작동하도록 내부 링크를 상대 경로로 구성했습니다. 빌드나 API 키 없이 `index.html`을 제공하면 됩니다. 지도 시안은 OpenStreetMap의 공개 타일을 사용하므로 인터넷 연결이 필요합니다.

## 디자인과 외부 자료

Apple Design 스킬의 타이포그래피·공간 구성·반응성·접근성 원칙을 참고했습니다: [emilkowalski/skills](https://github.com/emilkowalski/skills). Apple의 로고나 공식 사이트 자산은 사용하지 않았습니다.

포함된 외부 라이브러리·글꼴·지도 자료의 라이선스와 출처는 각 `demos/*/assets/`에 보관되어 있습니다. Leaflet, Gowun Batang, Klee, Natural Earth와 OpenStreetMap의 해당 표시를 유지합니다.

사이트에서 출시·계정 가입·실제 상대와의 연결·서버에 정보 전송을 제공하지 않습니다. 각 시안의 구현 범위는 사이트 상세 화면에서 확인할 수 있습니다.
